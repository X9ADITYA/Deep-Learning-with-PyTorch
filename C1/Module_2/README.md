# Module 2 – Building Your First Image Classifier

## Overview

In this module I built my first image classifier using the MNIST handwritten digits dataset.

The project walks through the complete deep learning workflow, from preparing image data to training and evaluating a neural network.

---

## Learning Objectives

- Load image datasets using Torchvision
- Apply image transformations
- Normalize image data
- Build neural networks using nn.Module
- Train models using backpropagation
- Evaluate model accuracy
- Visualize training metrics

---

## Dataset

- MNIST Handwritten Digits
- 60,000 Training Images
- 10,000 Test Images
- 10 Classes (0–9)
